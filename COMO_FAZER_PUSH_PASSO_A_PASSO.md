# 🚀 Como Fazer Push - Passo a Passo Completo

## 📋 O que você vai fazer

1. **Baixar GitHub Desktop**
2. **Fazer login no GitHub**
3. **Adicionar seu projeto**
4. **Publicar no GitHub**

---

## 📥 PASSO 1: Baixar GitHub Desktop

1. **Acesse**: https://desktop.github.com/
2. **Clique** no botão **"Download for Windows"**
3. **Instale** o programa (é rápido!)
4. **Abra** o GitHub Desktop

---

## 🔐 PASSO 2: Fazer Login no GitHub

Quando abrir o GitHub Desktop pela primeira vez:

1. Vai aparecer uma tela de boas-vindas
2. **Clique em "Sign in to GitHub.com"** (botão azul)
3. Isso vai abrir seu navegador
4. **Faça login** no GitHub no navegador
5. **Autorize** o GitHub Desktop a acessar sua conta
6. Volte para o GitHub Desktop
7. Pronto! Login feito! ✅

---

## 📁 PASSO 3: Adicionar Seu Projeto

1. No GitHub Desktop, clique em **"File"** (arquivo, no menu superior)
2. Clique em **"Add Local Repository"** (adicionar repositório local)
3. Uma janela vai abrir
4. Clique no botão **"Choose..."** (escolher)
5. **Navegue até a pasta do seu projeto**:
   ```
   C:\Users\natal\OneDrive\Documentos\Veredicta Software Jurídico\Veredicta_ Legal Petition Hub correto (5)\workspace\veredicta
   ```
6. **Selecione a pasta** `veredicta`
7. Clique em **"Add repository"** (adicionar repositório)
8. O GitHub Desktop vai mostrar seu projeto! ✅

---

## 🚀 PASSO 4: Publicar no GitHub

Agora que seu projeto está no GitHub Desktop:

1. Você vai ver uma mensagem no topo: **"This directory appears to be a Git repository"**
2. Ou vai ver um botão **"Publish repository"** (publicar repositório) no topo
3. **Clique em "Publish repository"**
4. Uma janela vai abrir com opções:
   - **Name**: `Veredicta` (já deve estar preenchido)
   - **Description**: (deixe vazio ou adicione uma descrição)
   - **Keep this code private**: ✅ **DEIXE MARCADO** (para manter privado)
   - **Account**: Selecione `VeredictaJus` (sua organização)
5. **Clique em "Publish repository"** (botão no final)
6. Aguarde alguns segundos...
7. **Pronto!** 🎉 Seu código está no GitHub!

---

## ✅ PASSO 5: Verificar no GitHub

1. **Abra seu navegador**
2. Acesse: https://github.com/VeredictaJus/Veredicta
3. Você deve ver todos os arquivos do seu projeto lá!

---

## 🎯 Próximo Passo: Conectar no Vercel

Depois que o código estiver no GitHub:

1. **Acesse**: https://vercel.com/new
2. **Clique em "Import Git Repository"**
3. Se não tiver conectado GitHub:
   - Clique em **"Configure Git Provider"**
   - Escolha **"GitHub"**
   - Autorize o Vercel
4. **Selecione o repositório** `Veredicta`
5. **Configure as variáveis de ambiente** (antes de fazer deploy!)
6. **Clique em "Deploy"**
7. Pronto! 🚀
