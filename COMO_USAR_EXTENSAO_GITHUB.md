# 🔧 Como Usar Extensão do GitHub no Cursor/VS Code

## ✅ Se Você Tem a Extensão Instalada

Você pode fazer commit e push pela interface visual!

---

## 📋 Passo a Passo

### **PASSO 1: Abrir Source Control**

1. Pressione **`Ctrl + Shift + G`** (Windows/Linux)
2. Ou **`Cmd + Shift + G`** (Mac)
3. Ou clique no ícone de **Source Control** na barra lateral (ícone de ramificação)

### **PASSO 2: Ver Arquivos Modificados**

1. Você vai ver uma lista de arquivos modificados
2. O arquivo `vite.config.ts` deve aparecer lá

### **PASSO 3: Adicionar ao Stage**

1. Clique no **`+`** ao lado do arquivo `vite.config.ts`
2. Ou clique em **"Stage All Changes"** para adicionar tudo

### **PASSO 4: Fazer Commit**

1. Na caixa de texto no topo, digite a mensagem:
   ```
   Fix: Tratar strings vazias do Vercel em vite.config.ts
   ```
2. Pressione **`Ctrl + Enter`** (Windows/Linux)
3. Ou **`Cmd + Enter`** (Mac)
4. Ou clique no botão **"Commit"**

### **PASSO 5: Fazer Push**

1. Depois do commit, você vai ver um botão **"Sync Changes"** ou **"Push"**
2. Clique nele
3. Aguarde alguns segundos
4. Pronto! ✅

---

## 🎯 Mensagem de Commit Sugerida

```
Fix: Tratar strings vazias do Vercel em vite.config.ts
```

Ou:

```
Fix: Corrigir VITE_APP_URL vazia causando erro de URL inválida
```

---

## ✅ Depois do Push

1. O GitHub vai receber o código
2. O Vercel vai detectar automaticamente
3. Vai fazer deploy em alguns minutos
4. O erro deve desaparecer! 🎉
