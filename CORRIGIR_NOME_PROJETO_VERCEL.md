# 🔧 Corrigir Nome do Projeto no Vercel

## ❌ Erro

O nome do projeto `VeredictaJus` está inválido porque contém letras maiúsculas.

---

## ✅ Solução

### **Regras para Nome do Projeto no Vercel:**

1. ✅ Deve estar **TUDO EM MINÚSCULAS**
2. ✅ Até 100 caracteres
3. ✅ Pode conter: letras, números, `.`, `_`, `-`
4. ❌ **NÃO pode conter** a sequência `---`
5. ❌ **NÃO pode conter** letras maiúsculas

---

## 🎯 Opções de Nome Válido

Escolha um destes nomes (todos em minúsculas):

1. **`veredictajus`** ✅ (recomendado - mais simples)
2. **`veredicta`** ✅ (mais curto)
3. **`veredicta-jus`** ✅ (com hífen)
4. **`veredicta_jus`** ✅ (com underscore)

---

## 📋 Como Corrigir

1. **No campo "Project Name"**, apague `VeredictaJus`
2. **Digite** um nome em minúsculas (ex: `veredictajus`)
3. O erro vai sumir! ✅

---

## ✅ Depois

Depois de corrigir o nome:
1. Configure as variáveis de ambiente
2. Clique em "Deploy"
3. Pronto! 🚀

---

**Mude o nome para minúsculas e o erro vai desaparecer!** 😊
