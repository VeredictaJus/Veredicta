## 🌐 Configurar Domínio Personalizado (Opcional)

Se quiser usar seu domínio próprio (`www.veredictajus.com.br`):

### **Passo 1: Adicionar Domínio no Vercel**

1. No Vercel, vá em **Settings** → **Domains**
2. Clique em **"Add Domain"**
3. Digite: `www.veredictajus.com.br`
4. Clique em **"Add"**

### **Passo 2: Configurar DNS**

O Vercel vai te mostrar instruções para configurar o DNS:

1. **Acesse** seu provedor de domínio (Hostinger, Registro.br, etc.)
2. **Encontre** a seção de DNS
3. **Adicione** os registros que o Vercel pedir:
   - Geralmente: `CNAME` apontando para `cname.vercel-dns.com`
   - Ou registros `A` (IPs) que o Vercel fornecer

4. **Aguarde** alguns minutos para propagar (pode demorar até 48h, mas geralmente é rápido)

### **Passo 3: Verificar**

1. Aguarde alguns minutos
2. Acesse: `https://www.veredictajus.com.br`
3. Deve funcionar! ✅
