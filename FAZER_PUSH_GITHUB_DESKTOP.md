# 🚀 Fazer Push usando GitHub Desktop (MAIS FÁCIL!)

## ✅ Por que usar GitHub Desktop?

- ✅ **Mais visual** - não precisa de comandos
- ✅ **Faz login automático** no GitHub
- ✅ **Não precisa de token** manual
- ✅ **Interface amigável**

---

## 📋 Passo a Passo

### **PASSO 1: Baixar e Instalar GitHub Desktop**

1. Acesse: https://desktop.github.com/
2. Clique em **"Download for Windows"**
3. Instale o programa
4. Abra o GitHub Desktop

### **PASSO 2: Fazer Login no GitHub**

1. Quando abrir o GitHub Desktop, ele vai pedir login
2. Clique em **"Sign in to GitHub.com"**
3. Faça login com sua conta do GitHub
4. Autorize o GitHub Desktop

### **PASSO 3: Adicionar Repositório Local**

1. No GitHub Desktop, clique em **"File"** → **"Add Local Repository"**
2. Clique em **"Choose..."**
3. Navegue até a pasta do projeto:
   ```
   C:\Users\natal\OneDrive\Documentos\Veredicta Software Jurídico\Veredicta_ Legal Petition Hub correto (5)\workspace\veredicta
   ```
4. Clique em **"Add repository"**

### **PASSO 4: Publicar no GitHub**

1. O GitHub Desktop vai mostrar uma mensagem: **"This directory appears to be a Git repository"**
2. Clique em **"Publish repository"** (botão no topo)
3. Uma janela vai aparecer:
   - **Name**: `Veredicta` (já deve estar preenchido)
   - **Description**: (opcional) deixe vazio
   - **Keep this code private**: ✅ Deve estar marcado (já que seu repositório é privado)
4. **DEIXE DESMARCADO** "Keep this code private" se quiser deixar público (mas recomendamos PRIVADO)
5. Clique em **"Publish repository"**
6. Aguarde alguns segundos...
7. **Pronto!** 🎉

---

## ✅ Depois do Push

Quando o push for concluído:

1. **Vá no GitHub** e veja seu repositório: https://github.com/VeredictaJus/Veredicta
2. Você deve ver todos os arquivos do seu projeto lá!
