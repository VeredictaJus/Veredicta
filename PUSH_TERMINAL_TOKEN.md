# 🚀 Fazer Push pelo Terminal com Token

## ✅ Por que usar Terminal + Token?

- ✅ **Mais rápido** que resolver problemas do Desktop
- ✅ **Funciona sempre** se você tiver o token
- ✅ **Poucos passos** simples

---

## 📋 Passo a Passo

### **PASSO 1: Criar Token de Acesso**

1. **Abra seu navegador** (não precisa do Desktop agora!)
2. **Acesse**: https://github.com/settings/tokens
3. Clique em **"Generate new token"** → **"Generate new token (classic)"**
4. **Configure o token**:
   - **Note**: `veredicta-push` (ou qualquer nome)
   - **Expiration**: Escolha um prazo (90 dias ou mais)
   - **Select scopes**: Marque ✅ **repo** (isso marca tudo dentro)
     - ✅ repo:status
     - ✅ repo_deployment
     - ✅ public_repo (ou repo se for privado)
     - ✅ repo:invite
     - ✅ security_events
5. Role até o final e clique em **"Generate token"**
6. **⚠️ IMPORTANTE**: **COPIE O TOKEN AGORA!** (você só vê uma vez!)
   - Vai aparecer algo como: `ghp_xxxxxxxxxxxxxxxxxxxx`
   - **Copie e guarde em um lugar seguro!**

---

### **PASSO 2: Fazer Push com o Token**

Depois que você tiver o token:

1. **Me diga**: "Tenho o token!"
2. **Eu vou executar o comando** para fazer push
3. Quando pedir autenticação:
   - **Username**: Seu usuário do GitHub (ex: `nataliayamao`)
   - **Password**: **Cole o token aqui** (não sua senha!)
